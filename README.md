StretchBIT — учебный антивирусный мультитул для школьного проекта.
Он не является сертифицированным антивирусом и не гарантирует обнаружение всех угроз.

Создан на базе языков программирования Python и C++

Условия использования и диагностики: [EULA](docs/EULA.txt).
Сторонние компоненты распространяются по собственным лицензиям из поставки.

В ZIP соглашение показывается при первом запуске и при изменении его редакции.
Сервиса отправки логов пока нет: кнопки отправки отключены, отчёт можно сохранить
только локально. Дополнительная диагностика и логи VPN требуют отдельных согласий.

Справочная документация для разработчика и нейросетей хранится в ветке
`docs/ai-reference`, а не в основной ветке приложения.
