# Как сохранить и обновлять эту ветку

Основное рабочее дерево — `myav` (main).
Вспомогательное рабочее дерево — `myav-ai-docs` (docs/ai-reference).
Коммиты выполняет пользователь: изменения в обоих деревьях независимы.

Сначала сохранить подготовленную документацию:

```powershell
git -C ..\myav-ai-docs status
git -C ..\myav-ai-docs add -A
git -C ..\myav-ai-docs commit -m "Документация для нейросетей: архитектура, аудиты и инструкции"
git -C ..\myav-ai-docs push -u origin docs/ai-reference
```

Затем отдельно проверить и закоммитить изменения программы в main.
Не переносить временные отчёты пользователей, логи, конфигурации или секреты.
Обновлять справочную базу явно по новым изменениям main. В этой ветке хранится
только ai/, исходники приложения остаются в main. Старые аудиты — исторические, не актуальный
список неисправленных уязвимостей.
